    💡 여행 팁

    🧥 겨울 옷차림 · 준비물
    • 체감 영하 10도 이하, 실내(지하상가·JR)는 난방이 강해요 → 레이어드 (히트텍+긴팔+가디건/경량패딩)
    • 아우터는 방풍·방수 + 모자 달린 것. 두꺼운 롱패딩 하나만 입는 건 비추
    • 하의: 기모 바지·조거팬츠. 통 큰 바지는 눈에 젖기 쉬움
    • 방한화 1순위: 고어텍스/방수 부츠, 미끄럼 방지 밑창. 어그 부츠·밑창 매끈한 운동화 비추
    • 방수 안 되는 신발은 출국 전 방수 스프레이 넉넉히
    • 아이젠 1,000~2,000엔, 방수 스프레이 700~1,000엔 → 돈키호테·편의점·드럭스토어
    • 붙이는 핫팩은 현지 드럭스토어에서 대용량으로 사기
    • 📝 블로그 원문
    🍛 스프카레 주문법 (5단계)
    • ① 메인: 치킨 레그 또는 가쿠니(돼지고기 조림)
    • ② 스프: 첫 방문은 오리지널
    • ③ 맵기: 4~5단계 = 신라면 정도
    • ④ 밥: 스몰/미디엄 + 치즈 토핑 추천
    • ⑤ 토핑: 튀긴 브로콜리 꼭!
    • 브레이크타임(15:30~17:00)이 많아요. 저녁 첫 타임은 16:20까지 도착
    • 웨이팅 길면 → 분점(스아게2·스아게4, 트레져) 또는 포장(15~20분 뒤 픽업)
    • 📝 비교 글 · 📝 웨이팅 팁
    🍖 징기스칸 웨이팅 팁
    • 다루마는 18시 피크에 2시간 대기 기본 → 17시 오픈 또는 22시 이후
    • 실내 대기: 5.5점, 7.4점 / 락커: 4.4점, 5.5점 / 삿포로 클래식 맥주·최신 환기: 6.4점
    • 냄새 싫으면 요조라노(야경, 예약), 마츠오(양념식, 입문자·아이), 비어가든(예약 필수)
    • 📝 지점 비교 · 📝 웨이팅 피하는 법
    ⛵ 오타루 당일치기 일정
    • 미나미오타루역에서 하차 → 내리막길로 운하까지 (오타루역에서 시작하면 오르막)
    • 상점가·오르골당은 17~18시 마감 → 부지런히!
    • 10:30 삿포로역 출발 → 11:30 오르골당·사카이마치도리 디저트 → 13:00 삼각시장 늦은 점심 → 15:00 운하 크루즈·카페 → 17:30 운하 야경 → 18:30 복귀
    • 삼각시장 식당은 14~15시면 재료 소진 마감 → 카이센동은 점심에
    • 📝 블로그 원문
    ✈️ 신치토세 공항 · 기념품
    • 국제선 면세구역은 작아요 → 수속 전 국내선으로 넘어가서 시간 보내기
    • 국내선 2층 디저트, 3층 라멘도조, 스마일로드 3층 로이스 초콜릿 월드, 4층 온천
    • 시로이코이비토: 호불호 없음, 유통기한 4~6개월 → 직장 선물
    • 롯카테이 버터샌드: 건포도 호불호, 유통기한 약 10일
    • 르타오 더블 프로마쥬: 냉동, 해동 후 2일 → 보냉백(약 100엔) 필수
    • 📝 공항 · 📝 면세 쇼핑
    🐟 니조시장 팁
    • 아침 일찍(7시 오픈) 조식 대신 방문 추천
